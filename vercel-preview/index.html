Net Banking

A responsive banking application built with Java, Jakarta Servlets, MySQL, and Tomcat.

Sign-in, account management, deposits, withdrawals, and transaction history are provided by its Java backend.

Vercel static preview

Application preview

This deployment is a visual preview only. The Java/Tomcat backend is not running on Vercel.

Banking actions are unavailable here. Do not enter account details or passwords on this preview.
  • Authentication and account creation are disabled
  • Balances and transaction history are not connected
  • No banking data is read or submitted by this page

For the complete application, run the WAR on a Java host with Tomcat and configure a hosted MySQL database.
